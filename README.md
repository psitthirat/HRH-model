# ว่าด้วยกำลังคนด้านสุขภาพและอนาคตประเทศไทย

เว็บไซต์ผลการวิจัยสำหรับอ่าน นำเสนอ สำรวจข้อมูล ดูภาคผนวก และทดลองแผนจัดสรรใน Workforce Lab

[เปิดเว็บไซต์](https://psitthirat.github.io/HRH-model/?mode=present&scene=S00)

[เปิด Workforce Lab](https://psitthirat.github.io/HRH-model/?mode=lab)

[สำรวจทางเลือกนโยบาย 20 ข้อ](https://psitthirat.github.io/HRH-model/?mode=lab&labview=policies)

Lab คำนวณแผนแพทย์ 76 จังหวัดสำหรับปี 2569–2583 จากสมมติฐานที่ปรับได้จริงในเบราว์เซอร์ เปรียบเทียบผลด้วยเกณฑ์ร่วม และดาวน์โหลดแผน Excel รายงาน HTML หรือชุดทดลอง ZIP โดยไม่ต้องมีบัญชี ฉบับร่างเก็บในเบราว์เซอร์ของผู้ใช้ ผลเป็นการทดลองภายใต้สมมติฐาน ไม่ใช่คำสั่งจัดสรรหรือผลที่จะเกิดขึ้นแน่นอน

ส่วนทางเลือกนโยบายแสดงตัวแปรที่ควรศึกษา หลักฐานต้นฉบับ และความพร้อมของตัวคำนวณทั้งไทยและอังกฤษ ประสิทธิผล ประสิทธิภาพ และความคุ้มค่าในไทยยังต้องประเมินเพิ่มเติม การเลือกนโยบายเปิดตัวควบคุมที่เกี่ยวข้องโดยไม่ใส่ค่าผลของนโยบายให้อัตโนมัติ

โครงการวิจัย: การพัฒนาแนวทางและนโยบายการวางแผนกำลังคนด้านสุขภาพโดยใช้แบบจำลองบูรณาการ

นพ.พีรสิชฌ์ สิทธิรัตน์ และคณะ · หน่วยวิจัยระบบและนโยบายสุขภาพ คณะแพทยศาสตร์โรงพยาบาลรามาธิบดี

## เปิดในเครื่อง

```bash
python3 -m http.server 8781 --bind 127.0.0.1 --directory site
```

เปิด `http://127.0.0.1:8781/?mode=present&scene=S00` มีฟอนต์และข้อมูลอยู่ในชุดเว็บ ไม่ต้องติดตั้ง Node.js

สไลด์และผลตั้งต้นของ Lab เปิดดูและดาวน์โหลดแบบออฟไลน์ได้ การคำนวณแผนใหม่ต้องโหลด Pyodide และแพ็กเกจ Python จาก CDN ที่ตรึงรุ่นไว้ จากนั้นคำนวณด้วยโค้ดแบบจำลองเดิมใน worker ไม่มีบริการรับข้อมูลแผนของผู้ใช้ไปคำนวณบนเซิร์ฟเวอร์

## การปรับปรุงเนื้อหา

`site/` เป็นชุดเผยแพร่ที่สร้างจากต้นฉบับของคณะวิจัย ห้ามแก้ตัวเลขใน JSON โดยตรง ให้แก้ต้นฉบับและสร้าง public export ใหม่เพื่อรักษาการเชื่อมโยงระหว่างกราฟ ข้อความ และข้อมูล

ชุดนี้ไม่มีบทผู้บรรยาย รายงานภายใน หรือข้อมูลรายบุคคล ข้อมูลกราฟ ตารางภาคผนวก และชุดคำนวณรวมระดับจังหวัดที่คณะวิจัยอนุมัติให้นำไปใช้ใน Lab อยู่ในเว็บไซต์และดาวน์โหลดได้ ชุดคำนวณรวมถึงสัมประสิทธิ์ M5 ชุด bootstrap ผลแผนเต็ม และโค้ดตัวแก้ปัญหา รายการไฟล์พร้อม SHA-256 อยู่ใน `site/publication.json`

GitHub Actions เผยแพร่เฉพาะ `site/` เมื่อ push `main` การตั้งค่า Pages ของ repository ใช้ **GitHub Actions** เป็น source

การอัปเดตเก็บข้อมูลของชุดเผยแพร่สาธารณะก่อนหน้าไว้สูงสุด 2 รุ่น เพื่อรองรับลิงก์ที่ระบุ `release` โดยคงข้อมูลและตัวคำนวณตามรุ่นเดิม ผลทดลองที่ต้องเก็บระยะยาวควรดาวน์โหลดเป็น ZIP/JSON

## แหล่งที่มา

นิยาม ขอบเขตประชากร หน่วย ตัวหาร และข้อจำกัดแสดงในส่วนข้อมูลและวิธีคำนวณของแต่ละสไลด์ ฟอนต์ Prompt ใช้ SIL Open Font License ซึ่งแนบไว้ใน `site/fonts/OFL.txt` โลโก้เป็นเครื่องหมายของหน่วยงานเจ้าของและใช้ตามไฟล์ที่คณะวิจัยให้ ภาพกาแล็กซีสร้างจากโค้ดในเว็บไซต์

Lab ใช้ SheetJS (Apache-2.0) และ fflate (MIT) สำหรับไฟล์ดาวน์โหลด โดยแนบใบอนุญาตไว้ใน `site/vendor/` รุ่นตัวคำนวณ สมมติฐาน แหล่งข้อมูลรวม และสถานะข้อจำกัดติดไปกับผลที่ส่งออกทุกครั้ง การแก้แบบจำลองบนต่างแพลตฟอร์มอาจให้แผนจำนวนเต็มต่างกันภายในค่าความคลาดเคลื่อนของตัวแก้ ส่วนผลตั้งต้นที่แสดงคงใช้แผนจากการนำเสนอ
